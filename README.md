# 哆哆赚钱

面向「价值投研小圈」的 Android 定制客户端，基于中富通 1.3.0 的本地修改版本。保留圈子名称、圈主头像及圈内使用习惯，需要使用自己的账号登录，并具备相应圈子权限。

[下载最新 APK](https://github.com/weisuodoadi1-svg/dodo-android/releases/latest) · [版本记录](CHANGELOG.md) · [构建说明](BUILDING.md)

## 功能

- **聊天室**：直接进入圈内聊天，支持只看圈主、我的消息、头像历史消息、引用回复、图片和表情。切回应用重连，滚动到顶部加载更早消息。
- **我的股票**：搜索添加本机自选，列表显示价格与涨跌，点击查看分时和 K 线。
- **AI 动态**：热点榜、精选资讯及图文详情，自动翻页，应用内阅读与返回。
- **界面**：五个底部入口、统一阅读排版、压缩的 ALL IN AI 开屏图；没有为了展示图片新增等待时间。

## 安装与更新

到 Releases 下载 `dodo-1.3.0-dodo.1.apk`，允许浏览器安装应用后安装。`SHA256SUMS` 用于核对下载文件。

- 已使用本项目同一签名版本：通常可以直接覆盖更新，保留登录与本地数据。
- 原版中富通或其他签名版本：可能提示签名冲突。不要直接卸载仍有未同步内容的应用；卸载会清除它的本机登录、缓存、设置和草稿。
- 推荐使用手机验证码登录。微信等第三方登录可能因客户端签名不同而无法使用。
- 自选保存在本机，行情可能延迟，不提供交易功能或收益承诺。
